Problem formulation:

The basis for many games is a physics engine.

You shall, using the pair-programming technique, write a program where the player can use the arrow keys (or WASD) to control the elevation and charge strength of a cannon, placed at one end of the window. The greater the charge, the greater the initial velocity V0 of the bullet. When the shot has been fired (i.e. left the muzzle of the barrel), the bullet trajectory must be affected by gravity so that the velocity in the y-direction Vy decreases by g in each time step. This means that after a while the ball turns downwards. At the other end of the window, there should be a target. If the ball hits the target, this must be marked. At the latest when the ball has hit or missed the target, it must be possible to fire the next shot.

The cannon is a very simple construction and essentially has two parts, a fixed base and a separate firing barrel that can be aimed (elevated) between 0° to 90°. The barrel must be long and narrow, i.e. the length is at least 6 times its diameter (or width when represented in 2D as in our case). The cannon must be implemented as two classes: Cannon and Barrel.

Tip: Keep in mind that the bullet should not stick out the sides of the barrel when it is fired. Do make use of the fact that you should start with pen-and-paper sketches! Then when coding, start with primitive figures (i.e. as sprites) so-called white boxing. Note that primitive figures sometimes have their pivot point (the point around which rotation occurs) in a different place than what you might have thought. Some methods such as spriteBatch.Draw() have overloaded alternatives with inputs that allows you to specify "origin" as pivot point.

For this task we will use MonoGame, a framework in C# for games (including Stardew Valley) which is now Open Source. Install the framework and create a new "MonoGame Cross Platform Desktop Project". Study the documentation and note how the game loop and graphical resources are handled in MonoGame. Create some primitive graphic objects (Sprites) and use the Update() method for translation, rotation, etc. of objects. This is also where you update physics effects etc. in the game. Note that Update() by default updates at 60fps, i.e. 60 times per second (how do you check this?). Instructions for installing/getting started as well as sample code can be found here on Studiewebben.

If you have time to spare: Remap WASD to control the lateral movement of the cannon as well as the elevation of the fire tube, and use ER for controlling charge amount (initial velocity V0). Experiment with textures and graphics. What can/should happen when firing a shot and the cannon is elevated to 90°?
